# IMDb Analytics: Полный цикл аналитики — от сырых данных до BI-дашборда

Pet-проект, демонстрирующий полный цикл работы с данными: от загрузки и очистки сырых TSV-файлов IMDb (~240 млн записей) до проведения углубленного анализа и подготовки агрегатов для BI-дашборда.

**Цель проекта:** продемонстрировать навыки:

*   Проектирование и загрузку данных в реляционную базу данных (PostgreSQL).
*   Проведение аудита качества данных.
*   Написание сложных SQL-запросов для извлечения и агрегации данных.
*   Проведение исследовательского анализа данных (EDA) с использованием Python (Pandas, NumPy, Matplotlib, Seaborn).
*   Выявление ключевых инсайтов и формирование бизнес-рекомендаций.
*   Подготовку данных для создания интерактивного дашборда.

## Стек технологий

*   **База данных:** PostgreSQL
*   **Язык запросов:** SQL
*   **Язык анализа:** Python 3.14
*   **Библиотеки:** Pandas, NumPy, SQLAlchemy, Psycopg3, SciPy, Matplotlib, Seaborn, Jupyter
*   **Окружение:** pip-tools, python-dotenv

## Данные

*   **Источник:** [IMDb Non-Commercial Datasets](https://datasets.imdbws.com/)
*   **Объем:** 7 TSV-файлов (в архивах `.gz`), суммарно **~240 миллионов записей**.
*   **Схема:** Все данные загружены в базу данных PostgreSQL в схему `imdb`. Ключевое отличие — использование `text` для идентификаторов (`tconst`, `nconst`) и создание нормализованных таблиц `genres` и `title_genres` для многозначного поля жанров.

## Как воспроизвести

1.  **Клонировать репозиторий:**
    ```bash
    git clone <URL_вашего_репозитория>
    cd Data_Analyst_IMDB
    ```
2.  **Установить зависимости:**
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # или .venv\Scripts\activate на Windows
    pip install pip-tools
    pip-compile requirements.in
    pip-sync
    ```
3.  **Настроить подключение к БД:**
    *   Скопируйте файл `.env.example` в `.env`.
    *   Заполните в нём данные для подключения к вашей PostgreSQL:
        ```
        DB_USER=your_user
        DB_PASSWORD=your_password
        DB_HOST=localhost
        DB_PORT=5432
        DB_NAME=imdb_db
        ```
4.  **Создать схему БД:**
    *   Создайте базу данных `imdb_db` в PostgreSQL.
    *   Последовательно выполните SQL-скрипты из папки `sql/` в следующем порядке:
        1.  `01_Create_table.sql`
        2.  `02_Foreign_keys.sql`
        3.  `03_Indexes.sql`
        4.  `04_Genres_Normalization.sql`
5.  **Скачать данные:**
    *   Скачайте все 7 TSV-файлов с [IMDb Datasets](https://datasets.imdbws.com/) и поместите распакованные архивы (`.tsv`) в папку `data/raw/`.
6.  **Запустить ноутбуки:**
    *   Последовательно выполните все ноутбуки в папке `notebooks/`, начиная с `01_load_to_BD.ipynb`.
    *   Файлы для дашборда DataLens будут созданы в папке `data/processed/`.

## Что сделано — ноутбуки 01–05

*   **`01_load_to_BD.ipynb`**: Загрузка 7 TSV-файлов в PostgreSQL с использованием команды `COPY` для высокой производительности. Проведена проверка соответствия количества загруженных строк.
*   **`02_data_quality.ipynb`**: Проведен аудит данных по 4 критериям: полнота, целостность, валидность, уникальность. Выявлены и объяснены особенности данных (например, высокая доля NULL в поле `runtimeMinutes` и аномально длинные произведения).
*   **`03_analysis.ipynb`**: Выполнен базовый исследовательский анализ: структура контента, динамика по годам, топ жанров по количеству и рейтингу.
*   **`04_advanced_analysis.ipynb`**: Проведен углубленный анализ с использованием сложных SQL-запросов и статистических методов (корреляция Пирсона/Спирмена): анализ комбо-жанров, влияние голосов на рейтинг, поиск "скрытых жемчужин" и топ лучших актеров/режиссеров.
*   **`05_for_datalens.ipynb`**: Подготовлены 7 агрегированных CSV-файлов (`dl_kpi.csv`, `dl_by_year.csv` и т.д.), которые будут использованы для построения дашборда в Yandex DataLens.

## Ключевые выводы (с цифрами)

1.  **Структура контента:** **77%** всех записей IMDb — это эпизоды сериалов (`tvEpisode`). Настоящие фильмы (`movie`) составляют лишь **6%**, что требует обязательной фильтрации при анализе кинематографа.
2.  **Динамика и качество:** Пик выпуска фильмов пришелся на **2024 год (21 510 фильмов)**. Несмотря на рост количества, средний рейтинг остается стабильным (~6.5-7.0), что говорит о стабильном качестве при экспоненциальном росте объема контента.
3.  **Жанровые предпочтения:** **Drama** — самый массовый жанр (**27 371 фильм**), а **Documentary** — лидер по среднему рейтингу (**7.19**). Ужасы (`Horror`) популярны массово, но имеют самый низкий средний рейтинг (**5.25**).
4.  **Трейд-офф "массовость vs качество":** Анализ комбо-жанров подтвердил эту гипотезу. Самые частые комбинации (Comedy + Drama, Drama + Romance) имеют средний рейтинг ~6.5, в то время как нишевые (Documentary + Biography) — > 7.2.
5.  **Эффект голосов:** Количество голосов — ключевой индикатор. С ростом числа оценок средний рейтинг растет (с **5.74** до **8.38**), а его разброс (std) резко падает (с **1.30** до **0.36**). Малое количество голосов = высокая неопределенность оценки.
6.  **Скрытые жемчужины:** Фильмы с рейтингом 8.0+ и 5K-50K голосов составляют ~1.6% от всех фильмов. Это идеальные кандидаты для редакционных подборок, так как их качество уже подтверждено лояльной аудиторией.
7.  **Люди как "знак качества":** Режиссеры — более сильный предиктор высокого рейтинга, чем актеры. У топ-10 режиссеров (Нолан, Чаплин, Вильдер) медианный рейтинг фильмов **8.0+**. У топ-актеров (Пачино, ДиКаприо) он стабильно ниже — **7.5–7.8**.

### Бизнес-рекомендации

*   **Стриминговым платформам:** Инвестировать в производство документальных фильмов и биографий — это нишевый, но высокорейтинговый контент. Создавать специальные разделы («Жемчужины IMDb») для продвижения недооцененных фильмов.
*   **Продюсерам:** Не гнаться за массовостью жанра. Согласно данным, нишевые проекты с качественным сценарием могут получить более высокую оценку аудитории.
*   **Маркетологам:** Использовать имена известных режиссеров как ключевой фактор в продвижении фильма, так как их участие является более сильным "знаком качества", чем актерский состав.

## Дашборд DataLens (в разработке)

Агрегаты подготовлены в `05_for_datalens.ipynb`. Планируется собрать дашборд из 3 страниц:

1.  **Общая картина:** KPI, динамика по годам, распределение по типам контента.
2.  **Жанры и комбо:** Топ-10 жанров по количеству и рейтингу, анализ комбо-жанров.
3.  **Топы:** Топ-10 фильмов, актеров, режиссеров.

## Ограничения и допущения

*   Данные IMDb отражают только зарегистрированные на платформе тайтлы и могут не соответствовать полной картине кинорынка.
*   Рейтинг IMDb чувствителен к числу голосов. Для анализа использовались фильтры (`numvotes >= 1000`), чтобы отсеять статистический шум.
*   Поле `title_akas.region` указывает на страну релиза альтернативного названия, а не на страну производства. Это важное допущение, которое следует учитывать при интерпретации географического анализа.
